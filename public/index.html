Semnale de alarmă

    Statistici live din PostgreSQL

    Fiecare apel real la Claude făcut de acest server se salvează într-o bază de date PostgreSQL, doar ca metadate (verdict, scor, durată). Textul mesajelor nu se păstrează.

    –analize în total
    –în ultimele 24 de ore
    –verdicte „periculos"
    –timp mediu de analiză
    Interogarea SQL din spatele cifrelor 
    SELECT
  count(*)                                                    AS total,
  count(*) FILTER (WHERE created_at > now() - interval '24 hours') AS last_24h,
  count(*) FILTER (WHERE verdict = 'dangerous')               AS dangerous,
  count(*) FILTER (WHERE verdict = 'suspicious')              AS suspicious,
  count(*) FILTER (WHERE verdict = 'safe')                    AS safe,
  round(avg(duration_ms))                                     AS avg_duration_ms,
  min(created_at)                                             AS since
FROM analyses;

    Drumul unei cereri

    Ce se întâmplă între momentul în care aplicația trimite un mesaj și cel în care primește verdictul.

    1. DNSapi.skutio.app → IP-ul serverului (A + AAAA)
    2. Firewall (ufw)deschise doar 22 (SSH), 80 și 443
    3. NginxHTTPS cu Let's Encrypt, rate limiting, headere de securitate
    4. Node.js + systemdascultă doar local, rulat ca user fără privilegii, restart automat
    5. Claude API + PostgreSQLprompt și cheie în afara codului; metadatele analizei salvate în baza de date
    6. Răspuns JSONverdict, scor, semnale de alarmă, recomandare

    Securitate server

    • Acces doar cu chei SSH, root și parole dezactivate
    • Firewall cu 3 porturi deschise
    • Aplicația rulează ca user fără shell și fără sudo
    • Actualizări de securitate automate

    Protecția API-ului

    • Secret partajat pe endpoint-urile AI (401 fără el)
    • Rate limiting pe IP în Nginx (429 peste limită)
    • Chei și prompturi în afara git, permisiuni 600/640
    • CSP strict și HSTS pe această pagină

    Operare

    • Serviciu systemd cu repornire automată (testat cu kill -9)
    • Loguri cu journalctl, câte o linie per cerere
    • Certificat HTTPS reînnoit automat
    • PostgreSQL cu migrații versionate și backup zilnic prin cron
    • Deploy documentat pas cu pas în README

    Flux de lucru

    • Branch-uri și pull request-uri pentru fiecare schimbare
    • Teste automate rulate de GitHub Actions la fiecare PR
    • Construit cu Claude Code, verificat pas cu pas
    • O singură dependență npm: driverul PostgreSQL (pg)
